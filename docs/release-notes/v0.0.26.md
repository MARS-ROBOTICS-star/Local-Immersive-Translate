# Local Immersive Translate v0.0.26

## 修复

- 修复 Gemini API 在当前网络地区不可用时，模型测试和翻译任务直接失败的问题。
- 修复 BabelDOC 对中文短表格行 `too long or too short` 的误判，短 CJK 文本不再因 token 比例被错误拒绝。
- 修复长文档默认请求额度不足的问题，`max_requests_per_document` 从 150 提高到 500。
- 修复单一段落渲染为空仍导致整篇任务失败的问题，改为保留原文并允许带警告完成。
- 修复 DeepSeek 模型测试缺少定价配置的问题，补充 DeepSeek V4 Flash 的输入、输出和缓存定价。
- 修复 DeepSeek `json_object` 响应格式要求提示词包含 `json` 的问题。

## 模型实测

- DeepSeek V4 Flash：价格最低，翻译一篇 60 页文献约 0.5 元。
- Gemini 3.1 Flash Lite：上下文吞吐量大，翻译效果较好，性价比也不错；翻译同一篇 60 页文献约 2-3 元。

## 兼容性

- 现有 Zotero 设置和模型 API 配置无需迁移。
- 长文档请求额度变化允许单篇任务消耗更多请求，实际计费仍由模型供应商决定。
